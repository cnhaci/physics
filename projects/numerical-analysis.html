PROJECT 02

Numerical Analysis of NOAA Weather Data

A computational analysis of 2024 weather data from Honolulu and Anchorage, focusing on temperature, humidity, wind speed, precipitation, sea level pressure, interpolation, and statistical relationships.

1. Introduction

Weather data provides a useful example of how numerical methods and computational tools can be applied to real-world scientific datasets. In this project, 2024 NOAA weather observations were analyzed using Python-based numerical and statistical techniques.

The main objective was to investigate temperature behavior and its relationship with other meteorological variables while also applying data cleaning, missing-value treatment, interpolation, and visualization techniques.

2. Project Overview

This project analyzes hourly meteorological observations from two geographically different locations: Honolulu, Hawaii and Anchorage, Alaska.

The analysis combines numerical processing, statistical analysis, interpolation, and data visualization to examine the structure and relationships within the datasets.

Main Objective:
To investigate weather patterns in 2024 and demonstrate how numerical analysis can be applied to real-world climatological data.

3. Dataset

The dataset consists of 2024 NOAA Local Climatological Data collected from Honolulu International Airport and Ted Stevens Anchorage International Airport.

Selected Variables

  • Hourly Dry Bulb Temperature
  • Hourly Relative Humidity
  • Hourly Wind Speed
  • Hourly Precipitation
  • Hourly Sea Level Pressure

The datasets were combined after selecting the relevant variables, and a station identifier was added to distinguish Honolulu and Anchorage observations.

4. Methodology

The analysis was performed using Python and several scientific computing libraries.

Data Preparation

The date information was converted into a datetime format. Additional Month and Hour variables were generated to support temporal analysis.

Numerical Conversion

Meteorological variables were converted to numerical values using numeric parsing. Invalid entries were treated as missing values.

Missing Values

Missing numerical observations were handled using linear interpolation. This allowed gaps in the dataset to be filled while maintaining the general trend of the measurements.

Statistical Analysis

Monthly averages, distributions, scatter plots, and correlation coefficients were calculated to investigate the behavior of the weather variables.

5. Key Results

The combined dataset showed a mean temperature of approximately 55.98 °F and a mean relative humidity of approximately 71.99%.

The average wind speed was approximately 8.58 mph, while the average precipitation value was approximately 0.0039 inches.

The observed temperature range extended from approximately -20 °F to 90 °F.

Honolulu showed a relatively stable temperature pattern throughout the year, while Anchorage displayed much stronger seasonal variation.

11. Discussion & Conclusion

The analysis demonstrates the usefulness of numerical methods for processing and interpreting real-world meteorological data.

The comparison between Honolulu and Anchorage clearly demonstrates the influence of geographical location on temperature variation. Honolulu exhibited a more stable temperature distribution, whereas Anchorage showed significant seasonal changes.

The statistical analysis also revealed relationships between the meteorological variables. Temperature and relative humidity showed a negative correlation, while wind speed and humidity displayed a stronger negative relationship.

Overall, the project demonstrates a complete numerical analysis workflow, from raw data processing and missing-value treatment to statistical analysis and scientific visualization.
